# 训练标签的修正：模拟标签和一阶标签（2026-11-10）

CAMPrior 的参照过程是 RLSA，翻转概率随状态变。CAM 的标签（`cam/solvers/cam.py:68`）默认“现在翻 i，这个扰动原样传到终点”，这只在参照与状态无关时成立（CAM 式 10–11、16–23）。本文给出两种修正后的标签，作为论文的关键消融：只换标签，其他训练设定不变。

- **模拟标签**（`--label_mode sim`）：从两个候选的下一状态出发真的跑 RLSA，对应 DAM 式 12（命题 2.3）。
- **一阶标签**（`--label_mode lin`）：不重新模拟，沿现有轨迹往回线性地算，对应 NAAS 式 22–23 的 Hessian 项。**结论（11-10）：在 RLSA 参照下不可用，不跑大图实验**：完整版本数值发散；删掉邻居反应项虽然不发散，但修正的实质也删掉了（3.8 节）。

## 1. 记号

离散时间，步 j = 0..K−1（K = num_tp = 50），每步每个坐标独立按 Bernoulli 翻转。

- 策略的翻转 logit：z_l(x) = a_l(x) + r_l(x)，p_l = σ(z_l)。
- 参照（RLSA 先验）：a_l(x) = (δ_l(x) − δ_(d)(x) + ε)/T_j，q_l = σ(a_l)。其中 δ_l = g'_l(2x_l − 1)/2，g' = 2β_p A x + b，δ_(d) 是第 d 大的 δ，T_j = τ_rlsa(j)·ratio。
- 目标：min E[g(X_K)] + τ Σ_j KL(p_j(X_j) ‖ q_j(X_j))，τ = τ_train。
- 策略下的代价函数：J_j(x) = τ KL_j(x) + E[J_{j+1}(X_{j+1}) | X_j = x]，J_K = g。
- 状态 X_k 处节点 i 的标签：比较“第 k 步不翻 i”和“翻 i”两种下一状态，
  T_i(k) = J_{k+1}(x⁰) − J_{k+1}(x¹)。
  它进 CAMPrior 的损失（`cam_prior.py`），最小点是 p* = σ(a + T·e^{−(1−w)}/τ)，正的 T 鼓励翻转。
- 沿轨迹的伴随向量：α_j(i) = J_j(X_j ⊕ e_i) − J_j(X_j)。
  记 s_i(k) = +1（第 k 步没翻 i）/ −1（翻了），则 T_i(k) = −s_i(k)·α_{k+1}(i)。

## 2. 模拟标签（方案 A）

T_i(k) ≈ g(Z(x⁰)) − g(Z(x¹))，Z(x) 是从 x 出发、在步 k+1..K−1 按参照 q 跑的一条 RLSA。

- 两条 rollout 用同一组均匀随机数（common random numbers）。每个状态共用一条“不翻”的 rollout。
- 一条 rollout 估的是参照策略下的期望终点能量差 E_q[g | x⁰] − E_q[g | x¹]，即 r = 0 时的 J 差；不是最优值函数 V = −τ log E_q[e^{−g/τ}] 的差。
- 每个状态均匀抽 10% 节点，没抽中的节点的整条损失（伴随项和 KL 项）都去掉，并乘 N/m，使损失是全量损失的无偏估计。
- 对照组：CAM 原标签，同样抽 10%、同样缩放。

## 3. 一阶标签（方案 B）的推导

### 3.1 一步的递推

用公共随机数把 X_j 和 X_j ⊕ e_i 两条路耦合起来：X' = x ⊕ F，F_l = 1[U_l < p_l(x)]；X'⁽ⁱ⁾ = (x ⊕ e_i) ⊕ F⁽ⁱ⁾，F⁽ⁱ⁾_l = 1[U_l < p_l(x ⊕ e_i)]。记 D = {l : F_l ≠ F⁽ⁱ⁾_l}，则 X'⁽ⁱ⁾ = X' ⊕ e_i ⊕ 1_D，于是

α_j(i) = τ[KL_j(x ⊕ e_i) − KL_j(x)] + E[J_{j+1}(X' ⊕ e_i ⊕ 1_D) − J_{j+1}(X')]。

### 3.2 三个近似

1. **残差不随扰动变（lean）**：r_l(x ⊕ e_i) ≈ r_l(x)，只保留参照 a 的变化。这和 NAAS 式 22 只保留参照漂移的 Hessian、丢掉控制项的雅可比是同一做法。
2. **top-d 门限不变**：δ_(d) 只在 i 或其邻居跨过门限时才变，忽略。
3. **一阶可加**：J_{j+1}(X' ⊕ Δ) − J_{j+1}(X') ≈ Σ_{l∈Δ} α_{j+1}(l)，Δ = {i} △ D。

### 3.3 参照 logit 的变化（MIS）

toggle i 只改 i 自己和它的邻居：

- 邻居 l（A_li ≠ 0）：Δa_l = β_p A_li (1 − 2x_i)(2x_l − 1)/T_j。
- i 自己：δ_i 变号（A_ii = 0），所以 Δa_i = −2δ_i/T_j。

翻转概率变成 p'_l = σ(z_l + Δa_l)。

### 3.4 用观测到的翻转做条件期望

U_l 只通过 F_l 和未来相关，所以给定轨迹上观测到的 F_l：

- F_l = 1：P(l ∈ D) = π_l = max(0, 1 − p'_l/p_l)
- F_l = 0：P(l ∈ D) = π_l = max(0, 1 − (1 − p'_l)/(1 − p_l))

### 3.5 一阶标签的递推

α_K(i) = g(X_K ⊕ e_i) − g(X_K) = (1 − 2x_i)(2βAx + b)_i（精确）

α_j(i) = τ ΔKL_j(i) + (1 − π_i⁽ⁱ⁾) α_{j+1}(i) + Σ_{l: A_li ≠ 0} π_l⁽ⁱ⁾ α_{j+1}(l)

ΔKL_j(i) = Σ_{l ∈ {i} ∪ N(i)} [κ(a_l + Δa_l, r_l) − κ(a_l, r_l)]，κ(a, r) = KL(Ber(σ(a + r)) ‖ Ber(σ(a)))

T_i(k) = −s_i(k)·α_{k+1}(i)，k = 0..K−1

### 3.6 读法和检查

- **(1 − π_i) α_{j+1}(i)**：i 自己的扰动以概率 π_i 被“吸收”。比如 RLSA 本来就会把 i 翻到好的一边：翻了 i 之后，δ_i 变号，它不会再翻回来，两条路在 i 上重合。CAM 的 (−1)^{x_t⊕x_1} 符号想表达的就是这件事，这里由参照自己给出。
- **Σ π_l α_{j+1}(l)**：邻居反应，NAAS Hessian 项的离散版本。
- **τ ΔKL**：NAAS 里没有。连续情形下这部分在最优点相互抵消，离散、状态相关参照下不抵消。r = 0 时 κ ≡ 0，这一项为 0。
- **均匀参照**（a ≡ 0）时 Δa ≡ 0、π ≡ 0，α 沿轨迹不变：T_i(k) = −s_i(k)(1 − 2x_i^K) g'_i(X_K)。和 CAM 的 (2x_i^k − 1) g'_i 只差 CAM 的那个符号约定和终点取 X_{K−1} 还是 X_K。

### 3.7 开销

每步每条链是一个 n × n 的邻居矩阵（KL 差要对邻居求和），ER-[700-800] 上在训练卡上就能算，不用抽样，不用额外的卡。

### 3.8 为什么不可用：连续空间能线性化，离散空间不能

**连续空间。** 一步更新 X_{t+dt} = X_t + b(X_t)dt + σdW，固定噪声后是 X_t 的光滑函数。起点挪 δ，下一步挪 (I + ∇b dt)δ，误差 O(δ²)，δ → 0 时消失。伴随方程（NAAS 的 Hessian 项来自 ∇b）算出的就是 ∇J 本身，而训练目标要的正是梯度，所以“一阶”没有损失。它也可能指数增长（混沌动力学，Metz et al. 2021），但那时真实梯度确实大。

**离散空间。** 一步更新 X_{j+1} = X_j ⊕ 1[U < p(X_j)]，固定随机数后是 X_j 的阶梯函数。网络输出和翻转概率是光滑的，但作用到状态上的是“翻 / 不翻”的二元结果。标签要的是翻一个比特的有限差 J(x ⊕ e_i) − J(x)，没有可以取无穷小的量。唯一可能小的是邻居翻转概率的变化 Δp = σ(z + Δa) − σ(z)，条件是 Δa = β_p/T ≪ 1。RLSA 的温度从 τ0 = 1 退火到约 0.002，整个过程 Δa ≥ 1，Δp 是 O(1)。

**为什么指数爆而真值有界。** 把两条耦合路径上“不同”的节点看成粒子：一阶递推假设它们各自繁殖、互不干扰，算的是粒子数的期望；每代平均后代数 (1 − π_i) + Σ_l π_l 在检查用的图上实测 1.1–1.35，50 步后到 1e5–1e8。真实的差异是一个集合，最多 n 个节点，同一个节点被两条连锁传到只算一次（按异或甚至会抵消），所以真值不超过能量的取值范围（n = 12 时精确标签平均绝对值约 0.05）。连续空间里无穷小扰动满足叠加原理，没有这个问题。代码本身没错：向量化版本和逐项循环版本一致（测试 9），最后一步精确（测试 10）。

**删掉邻居反应项也不行。** 只保留 i 自己的扰动（α_j(i) = τΔKL_j(i) + (1 − π_i) α_{j+1}(i)）不会发散（测试 12），但残差为 0 时它等于“终点翻 i 的能量差 × i 一直没被 RLSA 改回来的概率”，符号永远和终点差标签一样，只能压小、不能改方向。CAM 标签方向错的根源正是“邻居不反应”的假设，删掉邻居项等于回到这个假设。小图上它和精确值的相关系数 0.89–0.94，但这是把大量标签压成 0 赢来的：精确值 |·| > 0.02 的项只占约 6%；在这些项上，它有 24–54% 直接输出 0，不为 0 的那些符号一致率 0.80–0.97，和不打折的终点差标签（0.70–0.91）同档。

**两难。** 温度高时线性化准确，但邻居项接近 0，修正可以忽略；温度低时修正大，但线性化是错的。RLSA 的整个温度区间都在后一种情况。

**没排除的做法。** 往前传“每个节点在两条路径上不同的概率”（限制在 [0, 1]）不会发散，但要从每个 (步, 节点) 往前算，代价和模拟标签一个量级，已不是便宜的一阶近似，没有做。

**处理。** 大图实验（`CAMPrior_p1_linlab_e100_s0`，GPU 6）训了约 1 个 epoch 后于 11-10 停掉。代码（`solvers/lin_labels.py`，`--label_mode lin`，`--lin_neighbors`）和小图检查保留，用来复现上面的数字。

## 5. 记录但暂不做：终点先局部改进再算标签（2026-11-13）

**想法。** 现在第 k 步的标签用轨迹终点 X₁ 的翻转梯度 ∂H(X₁)·(2xᵢ−1)。可以先把 X₁ 做一次局部改进得到 X₁⁺（MIS / MCl 用 `envs/*.py` 的离散解码，即单点翻转到没有能下降的翻转为止），再在 X₁⁺ 上算同样的梯度。

**文献。** CAM 的 TSP 实验就是这么做的：代理目标 g = ‖x − X₁⁺‖₁，X₁⁺ 是 2-opt 改进后的终点（CAM, arXiv 2605.30920, §4.1）。表 5 的消融里只用贪心解码的终点是 2.36%，用改进后的终点是 2.18%。

**为什么暂不做。** 预期收益小：
- RLSA 先验在后期步骤本身就在做局部改进，X₁ 离局部最优已经不远，X₁⁺ 和 X₁ 多数时候只差几个点；
- 在局部最优 X₁⁺ 上所有翻转都不降能量（δ ≤ 0），标签只剩“保持现状”的方向，信息反而变少；
- 第 4 节的小图结果说明，标签的主要问题是 RLSA 参照下的偏差，而不是终点不够好，换终点不解决这个问题。

如果以后要做，开销很低：解码在训练时本来就会调用，只需把标签里的 X₁ 换成 X₁⁺，跑一条 ER-[700-800] 和 `CAMPrior_p1` 对比即可。

## 6. 标签什么时候是对的：均匀参照 vs RLSA 参照（2026-11-13）

脚本 `cam/scripts/mis/d3_label_theory.py`。小图（n = 12 的 ER 图，3 张）上用动态规划精确算；大图（ER-[700-800] test 前 4 张，主实验的 RLSA 先验 d = 20、τ0 = 1 线性退火、50 步）上用公共随机数（CRN）成对模拟。下面“参照过程”都指残差为 0、策略等于参照过程的情形，即 CAMPrior 初始化时。

**记号。** 第 k 步节点 i 的翻转决定：
- 精确标签 exact = m_{k+1}(X_{k+1}，i 没翻) − m_{k+1}(X_{k+1}，i 翻了)，m_j(x) = E_ref[g(X_T) | X_j = x]；
- CAM 标签 cam = grad_i(X_T)·(2x_i(k) − 1)，即 CAM 论文式 (23)/(30) 里带 (−1)^{X_t ⊕ X_1} 的形式；
- 去掉符号因子的标签 par = g(反事实终点) − g(实际终点) 的单样本，等于 grad_i(X_T)·(2(x_i(k) ⊕ p_i) − 1)，p_i 表示 i 在第 k 步之后是否又翻了奇数次。

**命题 1（已验证）。** 参照过程里每个节点独立翻转、翻转概率与状态无关（均匀，或每个节点、每一步各自固定的概率）时，用同一组随机数从两个候选状态出发，两条轨迹始终只差节点 i 一个位置（小图、大图逐步检查，Hamming 距离恒为 1）。因此 par 是 exact 的无偏单样本估计：

| 参照过程（小图） | \|exact\| | par：最大 \|z\|，相对偏差 | cam：最大 \|z\|，相对偏差 | 之后又翻奇数次的比例 |
|---|---|---|---|---|
| 均匀翻转（概率 d/n） | 0.069 | 2.4，0.53（蒙特卡洛噪声水平） | 158，38 | 0.48 |
| 与状态无关、按度数和时间变化 | 0.178 | 4.0，0.21 | 174，14 | 0.43 |

（每个设置 40 个条目 × 4000 对 rollout，3 张图取最大 \|z\|。）大图均匀参照下 par 和精确值的相关系数是 1.00；CAM 标签在第 0 步只有 0.46–0.53，到第 47 步升到 1.00。

所以“状态无关”就够了，不需要均匀，这比 DASBS 的条件宽。但在参照过程下，CAM 标签里的符号因子 (−1)^{X_t ⊕ X_1} 是错的。CAM 推出这个因子用了最优性条件（CAM 论文 Prop. 3.3、式 (20)–(21)），所以它可能只在最优控制处成立；这一点还没有推导核实。

| 0.1 | 25 | 4.9 | 18 | 35 | 0.14 | 24 | 0.5 | 4% | 0.01 |
| 0.1 | 47 | 5.3 | — | 9 | 0.13 | 11 | 9.4 | 73% | 0.94 |

改一个节点，下一步就有约 5 个节点不同，5 步后 20–45 个，到终点 35–85 个。RLSA 的 top-d 阈值把所有节点耦合在一起，单个节点的改变会改变阈值和邻居的 Δ，所以效应会扩散。除了最后几步，单个决定对终点能量的期望效应（约 0.2–1）远小于一对 rollout 的噪声（约 28），信噪比约 0.02。64 对 rollout 的平均也几乎没有可重复的信号（两半的相关系数约 0），模拟标签需要几千对 rollout 才能估准。这解释了模拟标签训练为什么停在 RLSA 的水平（第 20–100 个 epoch 39.8–40.1，RLSA 39.94）：它的标签几乎是纯噪声，网络学不到东西。CAM 标签（量级约 4.8）和精确值也不相关，所以它不是 RLSA 参照下精确标签的估计，而是一个方差低、有偏的信号，指向“终点上 i 应该在 / 不在”。

**命题 2（小图，RLSA 参照）。** K 对 CRN rollout 平均后，模拟标签和精确值的相关系数为：K = 1 时 0.06–0.44，16 时 0.22–0.78，64 时 0.48–0.92，256 时 0.78–0.97。独立随机数（不用 CRN）在每个 K 下都更低。单对 rollout 的噪声是精确标签的 20–50 倍。

**对 D2 的含义。** 在 RLSA 参照下，一个决定的效应在 1–5 步内就和后续轨迹去相关，终点梯度里关于这个决定的信息很少。这支持用近处步骤的梯度（较小的 λ），并给出一个可以检验的预测：λ 在 0.5–0.8 附近应该比 0.97 好。

> **2026-11-13 更正。** 上面最后一句的预测（λ 0.5–0.8 应该比 0.97 好）被后来的测量推翻：在真值可靠的步骤上，所有 λ 的 dense 标签和真值的相关都在 ±0.2 以内，见 §7.3。

## 7. 标签到底在估计什么（2026-11-13）

§6 用的“精确标签”是参照过程下只看终点能量的价值差，并且只在初始化（策略 = 参照）时测量。这一节换成 CAMPrior 目标真正对应的量，并在训练后的策略上重测。

### 7.1 正确的比较对象：软最优的价值差

CAMPrior 最小化 J(p) = E_p[g(X_T)] + τ·Σ_k E_p[KL(p_k(·|X_k) ‖ ref_k(·|X_k))]，X_0 均匀。它在所有（联合）转移核上的最优解是软最优过程
p*_k(x′|x) = ref_k(x′|x)·Z_{k+1}(x′)/Z_k(x)，Z_T = e^{−g/τ}，Z_k = ref_k Z_{k+1}，J* = E_{x0}[−τ log Z_0(x0)]。
CAM 的 adjoint 就是软价值 V* = −τ log Z 的差 V*(x^(i)) − V*(x)（CAM 论文 App. A.4 式 (81)）。CAM 的 lean 标签是在两个近似下得到的（CAM §3.3、App. A.4）：
1. 最优控制处的递推（Prop. 3.3），只在低温、t 远离 1 时成立；
2. 用终点的局部改进方向 ã_s ≈ ã_1 = ∇_flip g(X_1) 代替全局方向。附录明说这“隐式假设局部改进方向和全局方向一致”，违反时需要别的设计（比如正则）来防止陷入局部最优。

逐节点 loss 的理想标签是 p* 每个节点边际翻转 logit 与参照 logit 之差乘以 τ，记为 t*。一个标签“正确”，指的是 p* 是它的不动点：E_{p*}[标签 | X_k = x] ≈ t*。

- **规模的限制：** 这些小图上各种标签在小 τ 下都能找到最大独立集，所以解质量本身区分不了标签。

- **H3（“训练后 CAM 标签会变准”）不成立。** 在任何检查点上，cam 和各 λ 的 dense 标签与真值的相关都 ≤ 0.35，在真值完全可靠的 epoch 99 上也只有 −0.06–0.30。

### 7.4 图景

把每个 (步, 节点) 的翻转决定看作一个 agent，终点能量看作全队的回报，标签就是 agent 的个体回报。多智能体学习里，个体回报有两个性质（Wolpert & Tumer 2002 的 COIN 框架；Agogino & Tumer 2008, JAAMAS 17(2) 给出了测量方法）：
- **factoredness：** 个体回报的变化和全队回报的变化是否同号，即对齐；
- **learnability：** 个体回报主要由自己的动作决定，别人的动作贡献的噪声小。

二者通常此消彼长。“difference reward”固定别人的动作，只看自己动作的差。CAM 的 lean 标签正是这样一种 difference reward：它固定后续轨迹不动，只看终点上第 i 位的翻转差。按这个框架：

| 标签 | factoredness（与真值对齐） | learnability（信噪比） |
|---|---|---|
| CAM lean 标签及其变体 | 低：任何阶段与真值相关 ≤ 0.35；小图上不动点不是软最优 | 高：给定终点就是确定的 |
| 参照下的模拟标签（现有 sim） | 对参照下的价值无偏，但那不是当前策略的价值 | 极低：RLSA 下信噪比约 0.02 |
| 当前策略下的模拟标签 | 高：小图上不动点就是软最优（exact、softexact） | 训练初期极低，训练后期很高（单次 0.75–0.99） |

所以 CAM 标签能用，不是因为它估计了 adjoint，而是因为它是一个方差低、指向“终点局部改进”的信号。在 CO 任务上这个方向有用，代价是更贪心、和 KL 目标脱钩。这和 CAM App. A.4 自己的说法一致。D2 / D3 的各种 lean 变体（dense λ、去符号、分段）都在“固定后续轨迹”这一类里，不能解决对齐问题，测量也显示它们彼此没有实质差别。

### 7.5 可以检验的推论

如果上面的图景对，下面这个方案应该比纯 CAM 标签更好：初期用 lean 标签（此时模拟标签是噪声），训练到策略不再混沌后，换成或混入当前策略下的模拟标签。

最便宜的检验：从 `CAMPrior_p1` 的 epoch 50 检查点继续训练，比较三种标签：CAM 标签、现有的参照下模拟标签、当前策略下的模拟标签（新的 label 模式，rollout 用 先验 + 网络）。

开销：当前策略下的 rollout 要跑网络。每个被选中的 (状态, 节点) 要从 k+1 跑到 T，平均 25 步。
- 按现在 `--label_frac 0.1`（每状态约 75 个节点）算，是 CAM 生成数据开销的上千倍，不可行。
- 每个状态只取 1–2 个节点，约是生成数据开销的 25–50 倍。这时大部分节点没有标签，信号密度比 CAM 低得多。

风险：
1. 小图上 exact 标签在解质量上并不比 CAM 好（都到最优），优势只在 KL 效率。在 CO 指标上能否赢，要靠大图实验。
2. 当前策略下的模拟标签以策略自身为准，会强化策略已有的偏差。p* 是不动点只说明它对，不说明迭代一定收敛到它。
3. 训练后期温度比很低（0.01），策略近乎确定，探索不足。
